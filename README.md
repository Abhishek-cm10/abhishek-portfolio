# Abhishek CM — Portfolio

Premium, responsive, multi-screen React portfolio built with Vite.


## Run locally

1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the project folder and run:

   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Pages

- About
- Skills
- Projects
- Journey
- Contact
